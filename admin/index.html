设置 GitHub Token

  1. 打开 github.com/settings/personal-access-tokens/new（Fine-grained token）
  2. Repository access 选 Only select repositories →
  3. Repository permissions：Contents 选 Read and write，Actions 选 Read and write

Token 只保存在你的浏览器里，只会发送给 api.github.com。
