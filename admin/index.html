设置 GitHub Token

  1. 打开 github.com/settings/personal-access-tokens/new（Fine-grained token），建议设置过期时间
  2. Repository access 选 Only select repositories → 你的 RSS 仓库
  3. Repository permissions：Contents 选 Read and write，Actions 选 Read and write
  4. （可选）Secrets 选 Read and write：用于在本页更新 B 站 Cookie。该权限只能覆盖 Secrets，读不出原值
