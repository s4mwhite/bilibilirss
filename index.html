🔑 1 · 连接 GitHub 仓库

管理页本身是纯静态网页，保存时通过 GitHub API 把 ups.json 写回仓库。Token 只保存在你当前浏览器里，不会上传到任何地方。

如何创建一个 Token？（点开看步骤，只需做一次）
  1. 打开 github.com/settings/tokens/new（推荐选 Fine-grained 精细 Token）；
  2. Repository access 只勾选 Only select repositories 并选择这个 RSS 仓库；
  3. Permissions 里给 Contents 开 Read and write，其他保持默认；
  4. 有效期建议 90 天或更长，生成后复制粘贴到上面输入框。Token 过期后页面会提示 401，重新生成一个填入即可。
